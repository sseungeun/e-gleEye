# E-gle Eye
: Azure 클라우드 기반 실시간 화재 감지 및 스마트 알림 서비스

### 1. 프로젝트 개요 및 기획 의도

- **개발 배경:** 화재 사고는 초기 골든타임 확보가 생존의 핵심이지만, 기존 감지기는 오작동이 잦고 실시간 확인이 어렵다는 한계가 있음.
- **기획 의도:** CCTV 영상 데이터를 **Azure Cloud** 기반의 딥러닝 모델로 분석하고, **WebSocket** 통신을 통해 화재 감지 즉시 사용자에게 판단 근거(Grad-CAM)와 푸시 알림을 전달하는 실시간 안전 시스템 구축.

### 2. 주요 기능

- **실시간 화재 감지**: 딥러닝 모델(ResNet50)을 통해 영상 프레임 내 화재 발생 여부를 실시간으로 판별합니다.
- **실시간 데이터 송수신**: **WebSocket**을 활용하여 영상 분석 결과와 알림 정보를 서버-클라이언트 간 저지연(Low-Latency)으로 전송합니다.
- **판단 근거 시각화**: **Grad-CAM** 기술을 적용하여 AI가 이미지의 어느 부분을 보고 화재로 판단했는지 시각적으로 제시하여 신뢰성을 높입니다.
- **오탐 방지 로직**: 단순 감지를 넘어 **EWMA(지수 가중 이동 평균)** 알고리즘을 적용, 연속적인 화재 징후를 분석하여 일시적 노이즈에 의한 오보를 최소화합니다.

### 3. 기술 스택

| 분류 | 스택 | 
|------|------|
| 개발 언어 | **Python (AI/Backend), Kotlin (Android)** |
| AI & Logic | **ResNet50, Grad-CAM, EWMA Algorithm** |
| Infrastructure | **Microsoft Azure** | 
| Server | **WebSocket (Python based Server)** |
| Tools | **Jupyter Notebook, Pandas, PyTorch** | 

### 4. 주요 역할 (My Role)

- **서비스 기획 및 설계**: 페르소나 분석 및 User Journey Map 작성을 통한 전체 서비스 시나리오 및 시스템 아키텍처 기획
- **AI 모델링 및 최적화**: **ResNet50** 기반 화재 감지 모델 학습 및 **Jupyter Notebook**을 활용한 데이터셋 관리/검증
- **실시간 백엔드 로직 개발**: **Python** 환경에서 **WebSocket**을 활용하여 실시간 데이터 통신 및 알림 송출 로직 구축
- **판단 알고리즘 구현**: 오탐율 개선을 위한 **EWMA 알고리즘** 설계 및 모델 신뢰성 확보를 위한 **Grad-CAM** 시각화 구현
